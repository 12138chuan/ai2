姚佳男 · 苏州大学 2026 级 · 人工智能 · 学号 2662404078

## 三、五关设计

| 关卡 | 玩法 | 学到的点 | XP |
|---|---|---|---|
| **01 直线挑战** | 拖动画布平移直尺、滑块调角度，试着把两弯月亮分开 | 线性分类器有天花板：最好也会错 60 多个点 | 10 |
| **02 神经元调音台** | 调 w₁ / w₂ / b，让兴奋度 a ≥ 0.90 | 一个神经元 = 加权和 + 激活 | 20 |
| **03 长层实验** | 同心圆数据，训练 2-8-8-2 网络；可切换纯线性对比 | 隐藏层 + 非线性才能把圆「围」起来：100% vs 51.5% | 30 |
| **04 三道问答** | 三选一，答错给解析 | 激活函数的必要性、学习率过大、过拟合症状 | 30 |
| **05 过拟合怪** | 训练集里 15% 标签被贴反，观察训练场/考场两条曲线；用早停取胜 | 训练分数涨 ≠ 泛化能力涨 | 30 |

**通关条件**：前四关按提示完成即可；第 5 关要求「考场 ≥ 90% 且训练-考场差距 ≤ 6%」。

## 四、这些数字是真的（不是编的）

页面里所有曲线都来自浏览器里真实训练的模型，参数在开发时用 Node 标定过：

- **关卡 3**：同心圆 200 点，2-8-8-2 / tanh / Adam lr=0.03 / 300 轮 → **100.0%**；
  换成 2-2 纯线性 → **51.5%**（基本等于抛硬币）。
- **关卡 5**：双月 120 训练点（15% 标签翻转）+ 40 验证点 + 200 测试点，
  2-32-32-2 / tanh / lr=0.03：
  - 不早停练满 800 轮 → 训练场 98.3%，考场 **83.0%**，差距 15.3%
  - 用验证集早停 → 考场 **92%+**，差距 < 1%

所以「过拟合怪」是真的能被打败，也真的会把你打趴。

### 关于 `class MLP`

约 90 行，没用任何框架：

- `forward(x)`：逐层 `z = W·a + b` → 激活
- `trainStep(X, Y, lr)`：交叉熵 → 反向传播（链式法则）→ Adam
- `accuracy(net, pts)`：算准确率

关卡 3 和关卡 5 用的是同一个类，只是网络宽度、数据和早停策略不同。
